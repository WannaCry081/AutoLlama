Features

Built for local AI,
no cloud required.

AutoLlama proxies OpenAI-compatible clients to the best locally running Ollama model — automatic routing, full streaming, zero cloud.

Smart Routing
Classifies the latest user message and forwards the request to the best-configured Ollama model automatically.
OpenAI-Compatible API
Drop-in base_url for any OpenAI client. No API key needed — point it at http://127.0.0.1:8000/v1.
Configurable Buckets
Define MODELS and BUCKET_DESCRIPTIONS in .env. Add or remove model buckets anytime.
Direct Bypass
Skip auto-routing by passing a bucket name or raw Ollama model tag in the model field.
Streaming Support
Set stream: true to forward Ollama's event stream. AutoLlama prepends one routing comment per stream.
Router Metadata
Non-streaming responses include an x_router object with bucket, model, and source fields.
Health Check
GET /healthcheck returns Ollama connectivity status and the configured server URL.
Startup Validation
Checks bucket and description alignment, default bucket, and classifier bucket at startup before accepting traffic.

Getting Started

Up and running
in three steps.

Clone, start Ollama, and launch. The run script creates a virtual environment, installs dependencies, and starts the server automatically.

  1. 01

    Pull the Ollama models

    Download the four default model buckets AutoLlama expects.

    ollama pull qwen3:30b-a3b
ollama pull qwen2.5-coder:32b
ollama pull qwen2.5:7b
ollama pull deepseek-r1:14b
  2. 02

    Clone the repository

    Get a local copy of AutoLlama and enter the directory.

    git clone https://github.com/WannaCry081/AutoLlama.git
cd AutoLlama

    Start Ollama if it is not already running:

    ollama serve
  3. 03

    Launch AutoLlama

    The run script sets up a venv, installs dependencies, copies .env.example to .env on first run, and starts the server at http://127.0.0.1:8000. 

    ./run.sh
